# A股低位行业初筛工具

按"低位 + 行业出清 + 基本面边际改善"的思路，从实时数据中筛出研究候选清单。

1. 行业层：申万二级行业指数距近 4 年高点回撤 ≥ 30%，且处于区间价格下 35%
2. 公司层：总市值 ≥ 50 亿、市净率 ≤ 2、每股经营现金流 > 0、剔除 ST；优先显示营收同比转正且净利润环比改善的公司

## 使用

```bash
pip install akshare pandas   # 需要 Python 3.8+
python a_share_screener.py
```

结果输出到终端，并保存为 `候选清单.csv`。参数在脚本开头可调。

输出仅为研究候选，不构成投资建议。

## 在 GitHub 上运行

仓库 Actions 页面 → "A股初筛" → Run workflow。运行结果显示在运行详情页的 Summary 中，`候选清单.csv` 可在 Artifacts 中下载。工作日北京时间 16:00 也会自动运行一次。
